# Social SRS — فلش‌کارت معاشرت (نسخه‌ی ۲)

برنامه‌ی وب نصب‌پذیر (PWA) برای یادگیری مهارت‌های گفتگو و معاشرت با مرور فاصله‌دار. بدون وابستگی و بدون مرحله‌ی build؛ فقط HTML/CSS/JS ساده.

## اجرا

PWA فقط از **HTTPS** یا **localhost** نصب‌پذیر است؛ باز کردن مستقیم `index.html` با `file://` کار نمی‌کند (ماژول‌ها و سرویس‌ورکر اجرا نمی‌شوند).

- **آزمایش محلی:** در پوشه‌ی پروژه `python3 -m http.server 8080` بزن و `http://localhost:8080` را باز کن.
- **انتشار:** بخش «انتشار (GitHub Pages)» پایین را ببین. چون همه‌ی مسیرها نسبی‌اند، برنامه در زیرمسیر (مثل `/repo/`) هم کار می‌کند.

## نصب

| دستگاه | روش |
|---|---|
| Android / Chrome / Edge | دکمه‌ی «نصب» در صفحه‌ی اصلی یا تنظیمات (یا منوی مرورگر ← Install app) |
| iPhone / iPad | Safari ← دکمه‌ی اشتراک‌گذاری ← Add to Home Screen |
| ویندوز / مک | آیکن نصب در نوار آدرس Chrome یا Edge |

**تمام‌صفحه:** مانیفست روی `display: fullscreen` تنظیم شده و اگر پشتیبانی نشود به `standalone` برمی‌گردد. برای نمایش نوار وضعیت گوشی، در `manifest.webmanifest` مقدار `display` را `standalone` کن و آرایه‌ی `display_override` را حذف کن. داخل برنامه هم دکمه‌ی تمام‌صفحه برای مرورگرهای دسکتاپ و اندروید هست (iOS از Fullscreen API پشتیبانی نمی‌کند؛ نسخه‌ی نصب‌شده خودش تمام‌صفحه است).

## امکانات

- **مرور فاصله‌دار مدرن:** مراحل یادگیری (۱ و ۱۰ دقیقه)، ضریب سهولت، یادگیری مجدد پس از فراموشی، تشخیص کارت «مشکل‌دار»، سقف روزانه‌ی کارت جدید و مرور، «مرور زودتر»، «کارت جدید بیشتر»، و پیش‌نمایش فاصله‌ی بعدی روی هر چهار دکمه.
- **بازگردانی (Undo)** تا ۳۰ پاسخ، معلق کردن، «امروز نشان نده»، نشان‌دار کردن.
- **تمرین روزانه در دنیای واقعی:** هر روز یک قانون برای اجرا در گفتگوهای واقعی، با ثبت انجام‌شدن و یادداشت.
- **مرور آزاد** (تصادفی یا بر اساس برچسب) بدون تأثیر بر زمان‌بندی.
- **مدیریت کارت‌ها:** جستجو، فیلتر وضعیت و برچسب، افزودن/ویرایش/حذف (با امکان بازگردانی).
- **آمار:** پیش‌بینی ۱۴ روز آینده، نقشه‌ی فعالیت ۱۶ هفته، وضعیت کارت‌ها، دقت ۳۰ روز، زمان مطالعه، روزهای پیاپی. تاریخ‌ها شمسی‌اند.
- **ظاهر:** تیره/روشن/خودکار، ۵ رنگ اصلی، اندازه‌ی متن، ارقام فارسی یا لاتین، کاهش انیمیشن.
- **آفلاین کامل**، نشان تعداد کارت روی آیکن برنامه (در مرورگرهای پشتیبان)، میان‌برهای برنامه (مرور / کارت جدید) روی آیکن.
- **داده:** پشتیبان کامل JSON، خروجی دک JSON (سازگار با نسخه‌ی اول)، خروجی Anki، ورود از JSON/CSV/TSV.
- **میان‌بر صفحه‌کلید:** `Space` نمایش پاسخ / «خوب»، `۱–۴` امتیاز، `Z` بازگردانی، `E` ویرایش، `Esc` خروج.

## ساختار

```
index.html            پوسته‌ی برنامه
manifest.webmanifest  تعریف PWA (تمام‌صفحه، آیکن‌ها، میان‌برها)
sw.js                 سرویس‌ورکر (کش آفلاین)
css/app.css           استایل
js/srs.js             موتور SRS (خالص، تست‌شده)
js/store.js           وضعیت و ذخیره‌سازی (localStorage، نسخه‌دار، مهاجرت از نسخه‌ی ۱)
js/io.js              ورود و خروج داده
js/platform.js        نصب، تمام‌صفحه، سرویس‌ورکر، badge
js/util.js            DOM، آیکن‌ها، قالب فارسی، دیالوگ
.github/workflows/    انتشار خودکار در GitHub Pages
js/data.js            دک پیش‌فرض (۲۰ قانون)
js/packs.js, packs-more.js  دک‌های افزودنی ۲ تا ۴ (هرکدام ۲۰ کارت)
js/views/*.js         صفحه‌ها: امروز، مرور، کارت‌ها، آمار، تنظیمات، ویرایشگر
tests/                تست‌های واحد: node --test tests/*.test.mjs
```

## انتشار (GitHub Pages، خودکار)

با هر push روی شاخه‌ی `main`، فایل `.github/workflows/pages.yml` این کارها را انجام می‌دهد: تست‌ها را اجرا می‌کند، نسخه‌ی برنامه را با تاریخ و شناسه‌ی commit در `sw.js` ثبت می‌کند و سایت را منتشر می‌کند. لازم نیست `VERSION` را دستی عوض کنی.

راه‌اندازی یک‌باره: در GitHub به *Settings ← Pages* برو و *Source* را روی **GitHub Actions** بگذار. آدرس برنامه `https://<username>.github.io/<repo>/` می‌شود.

بعد از هر انتشار، برنامه‌ی نصب‌شده (هنگام باز شدن یا بازگشت به آن) نسخه‌ی جدید را پیدا می‌کند و پیام «نسخه‌ی جدید آماده است ← به‌روزرسانی» نشان می‌دهد.

نکته‌ها:
- اگر فایل جدیدی به پروژه اضافه کردی، مسیرش را به `ASSETS` در `sw.js` اضافه کن؛ تست `tests/assets.test.mjs` اگر یادت برود جلوی انتشار را می‌گیرد.
- روی GitHub Pages همه‌ی برنامه‌های یک حساب یک origin مشترک دارند؛ کلید ذخیره‌سازی (`ssrs.v2`) و پیشوند کش (`social-srs-`) این برنامه یکتا هستند. برنامه‌های دیگر هم باید کلید و پیشوند خودشان را داشته باشند.
- هنگام توسعه‌ی محلی (`python3 -m http.server`) در DevTools ← Application ← Service Workers گزینه‌ی *Update on reload* را روشن کن.

## فونت

برنامه از فونت‌های سیستم استفاده می‌کند (Segoe UI/Tahoma در ویندوز، San Francisco در Apple، Noto در اندروید). برای ظاهر یکدست می‌توانی [وزیرمتن](https://github.com/rastikerdar/vazirmatn) را کنار برنامه بگذاری: فایل `Vazirmatn[wght].woff2` را در پوشه‌ی `fonts/` قرار بده و این را به ابتدای `css/app.css` اضافه کن، سپس `"Vazirmatn"` را ابتدای `--font` بگذار و مسیر فایل را در `sw.js` به `ASSETS` اضافه کن.

```css
@font-face { font-family: "Vazirmatn"; src: url("../fonts/Vazirmatn[wght].woff2") format("woff2"); font-weight: 100 900; font-display: swap; }
```

## حریم خصوصی

همه‌ی داده‌ها فقط در `localStorage` مرورگر همان دستگاه ذخیره می‌شوند و جایی ارسال نمی‌شوند. برای جابه‌جایی بین دستگاه‌ها از «پشتیبان کامل» استفاده کن.
